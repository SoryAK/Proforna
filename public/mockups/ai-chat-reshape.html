Notes

  • Slash menu wins over icon. The trash icon's only function (clearChat) is replaced by /clear — discoverable because the menu auto-opens on /. Saves a column in the header.
  • Mode dropdown keeps the 4 tasks alive. Chat / Search / Think harder (Pro) / Summarize all remain selectable. Just no longer eating a full row.
  • Inline Model picker is a surface, not a duplicate. The Settings panel still owns Provider + Localhost URL; the toolbar's [Model ▾] is a fast-swap of the model within the chosen provider.
  • Mic is a stub. Renders disabled with tooltip "Dictation (coming soon)". Wires to ADR-0020 in a follow-up commit, not this one.
  • Context drawer is in-flow. Pushes the textarea down (or rather, raises everything above it) — same DOM slot as today, just gated. No portals.
  • Settings panel position unchanged. Still collapses below the header so it doesn't fight the toolbar for space. Only the trigger moved.
  • Avatars removed for familiarity. Industry-standard chat (ChatGPT, Claude, Linear) lets bubble alignment + colour carry the role signal. Saves ~28px of horizontal real estate per message and removes a second column of visual rhythm.
  • VS Code toolbar idiom. Ghost buttons (no borders), 1px vertical dividers between groups, icon-led with tiny text labels. Same density as the screenshot you shared.
  • Header drops to a single line. Bot icon + provider line were duplicating information already surfaced in the toolbar (Model pill carries provider+model via icon colour or label).
  • Slice rule respected. Pure layout/plumbing on ai-chat.tsx; one new state (contextExpanded); one new slash-command entry; one extra branch in executeSlashCommand. No new logic-bearing subsystem.
