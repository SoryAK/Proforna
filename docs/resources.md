## Dev logos

Developer, infrastructure, and project logos, as SVG and PNG.

- Repository: <https://github.com/falak-sh/cool-icons.git>
- A logo: `https://coolicon.falak.sh/i/<slug>.svg`
- Search: <https://coolicon.falak.sh>

Slugs are lowercase, such as `docker` or `nodejs`. The collection code is MIT. Each logo keeps the license recorded with it.

Brand logos as SVG.

- Site: <https://svglogos.dev/>
- A wordmark: `https://cdn.svglogos.dev/logos/<slug>.svg`
- An icon mark: `https://cdn.svglogos.dev/logos/<slug>-icon.svg`

The files are CC0.
