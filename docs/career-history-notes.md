# Career History — open notes

Notes for the selection bar on Career History. They record what two controls
are for. They are not a decision record.

## Edit

Edit was removed from the selection bar. The control focused the one checked
Role and showed the same read-only detail a row already opens: organization,
title, place, period, and summary.

If Edit returns, it opens an editor for that one Role. The fields are the
ones the occupant uses to change the Role, and saving writes those changes.
A Role the occupant can add has to be changeable from this bar. Showing the
detail leaves the Role unchanged.

## Ask

Ask is enabled for any checked set, including several Roles. The label does
not say what is being asked.

The checked Roles are the subject. Ask opens the Proforna conversation with
that set attached, so the question is about those Roles together. One Role
is a question about that Role. Several Roles are one question about the set.
The label should say that once the wording is settled.
