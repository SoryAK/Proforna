## Current Sprint

**Worklog Grill Me — markdown round-trip with YAML frontmatter.** Export per-worklog or in bulk to a `.md` file (or `.zip` of `.md` files), take it to an external AI for "Socratic grilling," then drop the rewrite back into the import dialog. The dialog auto-detects the Grill Me identity, routes to a re-import endpoint that uses a pure 4-case decision function (`decideImport`), and either writes the rewrite (firing an ADR-0017 auto-snapshot first) or surfaces a conflict / picker / not-found status without writing.

## Known Follow-Ups (deferred, not blockers)

1. **3-way diff modal for conflict status.** Right now conflict surfaces as an amber message; users can manually open the note + re-export. A visual diff modal reusing `WorklogVersionDiffModal` machinery would close the UX loop.
2. **Picker dialog for `needs-picker` / `not-found`.** Let users manually point a frontmatter-less file at a target worklog instead of being told "couldn't auto-link."
3. **Force-import override on conflict.** Server already auto-snapshots before write, so a "import anyway" button would be safe; just not built.
4. **Frontmatter HMAC signing.** Editable frontmatter is fine in current threat model; revisit if multi-tenant collaboration changes that.
5. **Google Drive sync.** Explicitly parked with re-entry criteria in `/memories/repo/parked-ideas.md` (≥5 round-trips/user/week sustained for 30 days).
