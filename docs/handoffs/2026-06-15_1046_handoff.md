- **Map renderer architectural choice**: `EventsMap` is a deliberate fork from `JobMapGoogle` (~13.3k LOC). Adding a 3rd mode would compound the god-file flag in ADR-0028. Visual parity (pink `#d946ef` + camera emoji 26px round 2px white border) maintained by duplicating the 6-line `escapeHtml` helper rather than cross-importing.
- **Shared TanStack queryKey** `["career-events", "all"]` is the single source of truth across `WorklogEventsView`, `WorklogMapView`, and the sidebar Events badge. Mutations invalidate this key — never fork it.
- **`eventPatchUrl(event)` helper** exported from `event-edit-dialog.tsx` is the central PATCH router (anchored vs floating). Both PATCH endpoints reject `workHistoryId` in the body — geo is immutable post-creation per ADR-0027 Q1=A. Floating POST forces `workHistoryId=null` server-side defense-in-depth (Q2=B).
- **`<FullBleedShell>` is `h-full`, NOT a flex container.** Children must use `h-full flex flex-col` as their root. Captured in `LayoutShellDomain` memory + maps.md UI graph.
- **MCP Memory 503 recovery**: VS Code's MCP client holds a long-lived SSE on port 3717 → worker. Service restart loses to VS Code's instant-reconnect. Fix is **VS Code-side only**: Command Palette → "MCP: Restart Server" → pick `memory-resumsify`, OR "Developer: Reload Window". Captured in user memory under MCP Memory Supervisor section.
