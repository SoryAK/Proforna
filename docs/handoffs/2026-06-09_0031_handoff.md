### Architectural commitments crystallized this session

- **Provider/mode seam contract:** `onFinalChunk(text: string)` is the surface API. Future Whisper / AICore providers MUST emit the same shape. Per-surface callsites never change.
- **Single shared prefs cache key:** `["worklog-preferences"]`. Do NOT fork to `["voice-consent"]`. `useVoiceConsent` is a projection, not a separate cache.
- **Error code transparency:** Every voice error must surface the raw Web Speech `code` to the user as `(diagnostic: code="...")` so bug reports are deterministic. Pattern lives in `voice-dictation-button.tsx` and is the template for future provider error handling.
- **5-minute hard cap** on every session per ADR-0020 — surfaces cannot extend.
- **Strategic reframe:** Resumsify is targeting Play Store + iOS, not just web. ADR-0021 codifies "defer all AI provider implementations to mobile sprint." All AI-adjacent UX (consent, error shapes, prompts) continues now but must stay provider-agnostic.
- **"Grill Me" tactic** parked under ADR-0021 as Tactic V0 — provider-neutral markdown round-trip (frontmatter `id` + `version`), reusable for Gemini / ChatGPT / Claude / Obsidian. **"Don't build a Gemini feature. Build a markdown round-trip feature."**
