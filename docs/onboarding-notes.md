# Onboarding — open notes

Notes for the live onboarding screen. They record follow-ups. They are not a decision record.

## Integration marks

The Gmail, GitHub, and LinkedIn rows on the Integrations step use Heroicons: an envelope, a code bracket, and a link. Those stand in for the services. They are not the services' own brand marks.

Swapping in the real brand marks for those three rows is a follow-up. The catalog and the plugin definitions do not carry a logo today, and the settings rows use the same kind of stand-in icon.
