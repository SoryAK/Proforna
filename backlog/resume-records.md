# Resume records

Two kinds of resume record can be added but not fully changed or removed, which breaks the rule in AGENTS.md. Held back on purpose; pick up when resume work resumes.

## Problem

- Resume variants in Resume Studio can be added and given new revisions, but not renamed or removed.
- Removing an uploaded resume during setup only hides it in the browser. The file and its record stay on the server.

## Direction

Give a resume variant change and remove with the same fields that add it; its revisions are history and go with it. Make removing an uploaded resume delete its file and record on the server, through the shared upload path check, and drop its evidence unless a career fact cites it.
