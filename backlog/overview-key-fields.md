# Overview key fields

The overview stats for a job need a defined set of key fields. This applies to the per-role overview in focus mode and to overview mode itself.

## Problem

Focus mode can surface counts from a role, and overview mode shows career totals. Neither has a settled list of what belongs in that glance. The focus card currently lets someone choose from the counts the role already stores. That choice is a stand-in, not the key set.

## Direction

Decide the key fields for a role, and the key fields for the career overview, before treating either card as finished. Keep the boxed stats. Do not invent counts the role does not store.
