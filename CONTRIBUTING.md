# Contributing

Proforna is being rebuilt from a small base. Issues, PRs, and design discussion
are welcome.

1. Open an issue before a large change, using the body in
   [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md). A UI change
   includes at least three detailed mocks for review.
2. Keep a pull request to one concern.
3. Review the branch against that issue before the pull request is ready.
   Standards: it follows this repo. Spec: it does what the issue asks.
   Write both on the pull request. Pushing the branch is allowed; that push
   is what opens the pull request.
4. The merge gate is [docs/ci.md](docs/ci.md). The `test` check must pass.
   It does not replace the review.
5. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Report vulnerabilities privately — see [SECURITY.md](SECURITY.md).
