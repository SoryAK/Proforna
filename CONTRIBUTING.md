# Contributing

Proforna is being rebuilt from a small base. Issues, PRs, and design discussion
are welcome.

1. Open an issue before a large change, using the body in
   [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md). A UI change
   includes at least three detailed mocks for review.
2. Keep a pull request to one concern.
3. The merge gate is [docs/ci.md](docs/ci.md) (GitHub check name: `test`).
4. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Report vulnerabilities privately — see [SECURITY.md](SECURITY.md).
